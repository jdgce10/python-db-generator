# CLAUDE.md

## Objetivo

Este proyecto debe mantenerse con calidad profesional.

No generar código rápido.

Priorizar:

- claridad
- mantenimiento
- escalabilidad
- seguridad
- documentación

---

## Lenguaje

Python 3.13

---

## Arquitectura

Modular.

Cada archivo debe tener una única responsabilidad.

Evitar funciones enormes.

---

## Estilo

PEP8

Type hints siempre que sea posible.

Comentarios únicamente cuando aporten valor.

Variables descriptivas.

---

## Seguridad

Nunca guardar secretos.

Nunca hardcodear contraseñas.

Validar entradas.

Manejo correcto de errores.

---

## Testing

Cada nueva funcionalidad debe tener pruebas.

---

## Documentación

Actualizar README.

Actualizar docs.

Actualizar CHANGELOG.

---

## Git

Después de cada tarea:

Proponer mensaje de commit.

Nunca modificar múltiples módulos sin justificarlo.

---

## Antes de escribir código

1. Analizar el problema.

2. Explicar el enfoque.

3. Esperar aprobación si el cambio es grande.

---

## Después del código

Revisar:

- bugs
- rendimiento
- seguridad
- legibilidad

Proponer mejoras.
